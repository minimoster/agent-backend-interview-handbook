# 静态阅读页

本目录提供知识点、八股、面经、算法四类导航、中文全文搜索、章内目录、题目筛选、代码复制与下载、明暗主题，以及本机收藏与已读标记。阅读内容统一为题目、解析、答案和必要代码。

## 打开阅读

- 在线入口：https://minimoster.github.io/agent-backend-interview-handbook/
- 离线阅读：下载仓库后，用现代浏览器打开 `site/index.html`。脚本、样式、阅读数据与关联代码均为本地文件，无需联网。
- 本地预览：在仓库根目录运行 `python -m http.server 8000 --directory site`，然后打开 `http://localhost:8000`。

不需要账号、后端、CDN 或外部字体。收藏、已读与上次阅读位置只保存在当前浏览器，不上传、不跨设备同步。清除浏览器数据会清除这些记录；禁用本地存储时，当前会话仍可使用。

## 怎样使用

1. 从唯一学习路线进入，按主题阅读。顶部搜索可匹配题号、标题、正文与代码中的关键词。多个词用空格分隔，要求全部匹配；按 `/` 或 `Ctrl/Cmd + K` 聚焦搜索。
2. Hot100 保留 100 题和 17 个算法主题。15 道算法补充、26 张场景卡与 34 道 SP 练习独立计数，不增加原有 364 + 100 = 464 个索引条目。
3. 本章目录直接定位小节；知识区和答案可以折叠。代码支持横向滚动、复制与必要的源码下载。项目讲解保留对应固定版本代码位置。
4. 正文字号、行距与明暗主题可随时调整。手机导航支持 Esc 关闭和键盘焦点约束。

分类入口由 `data/learning-taxonomy.json` 登记，题目入口直达原正文锚点。知识点按篇理解，八股按题口述；面经按有依据的公司与明确轮次筛选，原创模拟单列；算法主题、数据结构与具体解法分别筛选。文末关联用于概念复习和方法对照，旧阅读 URL 与本机收藏保持兼容。

## 构建与检查

内容在 `docs/`、仓库索引和配套 `examples/` / `tests/` 中维护。`data/reading-catalog.json` 仅保存补充题与场景卡的教学分类、题号、路径和锚点。`site/assets/data.*.js`、`site/assets/data.js` 与 `site/assets/repo/` 均为自动生成文件，不在其中修正文。

需要 Node.js 20 或以上；构建不联网，也不安装依赖：

```bash
node site/build.mjs
node site/build.mjs --check
node site/test.mjs
node --test site/taxonomy.test.mjs
```

- 阅读白名单只包含教学 Markdown、根目录学习入口与题目索引。维护记录和验证日志不注册为阅读页，不进入搜索或下载镜像。
- HTML、搜索段落和阅读数据使用同一清理边界。仅复制白名单中的教学源码与必要练习输入，重建会清除旧分片和多余镜像。
- 数据分片使用 SHA-256 摘要命名；脚本和样式同步使用该摘要更新缓存键。同一套输入得到相同输出。
- `--check` 验证已提交产物与当前输入完全一致，包括分片和镜像白名单。`test.mjs` 检查索引、锚点、全文搜索、输出边界、代码保真及非渲染运行时；不代替浏览器或辅助技术实测。
- 旧学习路线地址和小节在 `site/config.json` 中映射到唯一正文。本机收藏、已读和继续阅读位置会合并到该路径。

Markdown 渲染器 Marked 17.0.5 的 MIT 许可保存在 [vendor/marked.LICENSE.md](vendor/marked.LICENSE.md)。构建器只允许必要的 Markdown 锚点，不执行原始 HTML 或脚本。

## GitHub Pages

`.github/workflows/pages.yml` 发布已提交的 `site/` 静态文件，不在部署时重建。修改教学内容后先运行构建与检查，再一并提交正文和产物。保留 `index.html`、`.nojekyll` 和完整 `assets/`；相对资源路径及 hash 路由同时支持在线与离线阅读。
