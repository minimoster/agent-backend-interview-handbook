## 本地执行

最终云端复跑使用Python 3.12.14、标准库，无依赖安装、网络服务或用户数据：

```sh
python -B -m unittest discover -s examples/retrieval_worked_examples -p 'test_*.py' -v
```

22个测试方法通过：检索指标/排序11项、构树10项、之字形层序1项。Top-K含250组固定种子输入与独立完整稳定排序对拍；RRF算例使用Fraction有理数参考；构树包含5000节点深链、正常树之外的独立环及不修改输入检查。之字形覆盖空树、单节点、非完整树与单链，并检查输入未修改。循环数据不另增测试方法计数。

研究阶段在Python 3.12.14通过原21项；原21项曾在Python 3.14.6复跑。最终补齐逐题答案后，在云端Python 3.12.14运行22项；新增之字形测试未在3.14.6运行。本地复跑不证明所有Python版本、任意输入或递归序列化深度均支持。代码要求Python 3.10+；仅用本页列明的运行环境报告实测结果。

来源检查器验证19个唯一URL、18个作者标签；原P01–P17记录以规范JSON摘要验证未改，新两条检查schema、正文链接、核查日期及原创模拟标记。原26张场景卡、361讲义＋100 Hot100、虾皮34题、SQL九题和唯一六周路线保持原口径。
