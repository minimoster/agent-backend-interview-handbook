## 派生长度与分区题数

`all-question-manifest.json`的`chars`统计Unicode码点，不统计UTF-8字节，也不按显示字形计数。原文不做换行或空白归一化：从编号题目的Markdown标题开始，计至下一个题目显式锚点、同级或更高级标题之前，或文件结尾；不包含本题标题前的显式锚点，下级追问参考答案仍属本题范围。例如R12按此范围计数，不把题前锚点算进长度。

运行[元数据脚本](../tools/refresh_question_metadata.py)：`python3 -B tools/refresh_question_metadata.py`刷新全部长度及QUESTION_INDEX中带题数的分区标题；加`--check`只检查。分区数由对应索引条目计算，脚本不会全局替换正文数字、状态码或序列容量。题号与题目清单是计数依据，长度变化不意味着新增一道题。
