# Java顺序输出实验

题解：[FJ46 三线程按序输出](../../docs/20-java/15-thread-ordering-lab.md#fj46)。源文件为原创实现，与讲义代码一致。

```sh
java examples/java/OrderedPrinter.java
```

2026-10-09在OpenJDK21.0.12.1运行，并独立再次复跑：101个正常用例、工作线程中断、工作线程异常、协调线程中断清理均通过。程序断言角色/数字顺序、ABC重复输出和正常输出完整性，并join所有工作线程。异常分支允许输出合法前缀，不要求未完成工作继续输出。

有限实验不是对任意线程调度、JVM崩溃或内存耗尽的形式化证明。本例假设可运行线程最终得到调度。
