# 原创场景合同实验

纯Python标准库，无商家连接、支付、模型请求、网络访问或真实个人信息。

运行：

```sh
python -m unittest -v test_ordering.py
```

从本目录执行。覆盖批准与预览绑定、身份隔离、价格变更使批准失效、取消、同操作已知结果复用、先执行后超时的未知状态、独立查询后的恢复，以及步数/无进展停止。

这不是生产幂等或支付实现。Approval对象只模拟可信服务端确认边界；模型不能创建真实批准。对象字段是教学内存状态，不抵御同进程代码篡改、并发竞争、进程崩溃或外部重试；生产需要数据库原子转换、操作账本、执行时授权和供应商合同。reconcile_created必须来自独立核实的查询，不能直接相信模型或客户端传来的订单ID。

没有测试真实网络、SDK、数据库、商家、SSE前端或付费操作。测试只证明列出的合成分支符合教学模型。
