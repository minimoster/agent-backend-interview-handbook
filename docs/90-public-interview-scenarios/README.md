# 场景题解与可验证练习

本模块组织26张场景卡，配合原理、参考答案、追问与验收。结合基础章节，练习把正常流程和失败处理讲清楚。

## 配套练习

4个标准库 Python 练习包含33项本地测试；12条合成评测设计仍待运行模型。

## 第一次实习怎样用

1. 先做SC-A01。用一个目标判断固定工作流是否够用，再讲模型、工具、状态、权限与退出条件
2. 用SC-A02–SC-A05拆RAG链路。手算SC-A03的RRF，再用合成设计练证据、无答案、权限与版本样本
3. 做SC-A06–SC-A10。画超时未知结果、重复副作用、checkpoint与并发写入的时间线，运行版本和库存练习
4. Java先SC-B03、SC-B05、SC-B11；Go先SC-B01、SC-B02。然后接SC-B07/B08、SC-B09/B10、SC-A11/SC-B13与SC-B12
5. 最后用SC-B14与SC-A12准备项目表达：本人工作、失败样本、版本、指标分母、尾延迟和成本。无法验证的规模与收益留空

每轮可用30–60分钟：先理解，再口述，再画失败时间线或做练习，最后记下一条仍不能解释的追问。
