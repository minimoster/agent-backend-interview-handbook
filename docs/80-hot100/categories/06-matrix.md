# 矩阵：4题

矩阵题先画坐标与边界。原地修改要防止新写入数据污染“原始状态”，遍历要防止最后一行或一列被读两次。

## 本类题目

- [73. 矩阵置零](../problems/0073-set-matrix-zeroes.md) · 中等 · 首行首列充当标记，单独记录它们原始状态
- [54. 螺旋矩阵](../problems/0054-spiral-matrix.md) · 中等 · 四边界模拟
- [48. 旋转图像](../problems/0048-rotate-image.md) · 中等 · 转置后逐行反转
- [240. 搜索二维矩阵 II](../problems/0240-search-a-2d-matrix-ii.md) · 中等 · 右上角阶梯搜索

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
