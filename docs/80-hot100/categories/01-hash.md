# 哈希：3题

哈希表适合把“反复扫描找匹配”变成“按键直接找到历史信息”。先明确键代表值、字符多重集合还是连续段起点，字典值是下标、频次还是分组。

## 本类题目

- [1. 两数之和](../problems/0001-two-sum.md) · 简单 · 哈希表：先查补数，再存当前下标
- [49. 字母异位词分组](../problems/0049-group-anagrams.md) · 中等 · 哈希键分组：排序字符串或字符计数元组
- [128. 最长连续序列](../problems/0128-longest-consecutive-sequence.md) · 中等 · 哈希集合：只从连续段起点向右走

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
