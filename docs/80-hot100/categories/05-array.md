# 普通数组：5题

普通数组题常把重复计算拆成前后信息，或用原位置存放登记状态。必须明确是否允许修改输入，排序、切片和返回数组的空间应单独计算。

## 本类题目

- [53. 最大子数组和](../problems/0053-maximum-subarray.md) · 中等 · Kadane 动态规划
- [56. 合并区间](../problems/0056-merge-intervals.md) · 中等 · 按起点排序后合并
- [189. 轮转数组](../problems/0189-rotate-array.md) · 中等 · 三次原地翻转
- [238. 除了自身以外数组的乘积](../problems/0238-product-of-array-except-self.md) · 中等 · 前缀积和后缀积
- [41. 缺失的第一个正数](../problems/0041-first-missing-positive.md) · 困难 · 原地置换：值 x 放到下标 x-1

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
