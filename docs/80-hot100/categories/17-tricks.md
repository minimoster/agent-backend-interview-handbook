# 技巧：5题

技巧题往往依赖明确前提：异或消去成对值，多数投票要求多数确实存在，环检测依赖值域映射。先验证题设再套模板。

## 本类题目

- [136. 只出现一次的数字](../problems/0136-single-number.md) · 简单 · 异或消去成对数字
- [169. 多数元素](../problems/0169-majority-element.md) · 简单 · Boyer–Moore 多数投票
- [75. 颜色分类](../problems/0075-sort-colors.md) · 中等 · 荷兰国旗三指针
- [31. 下一个排列](../problems/0031-next-permutation.md) · 中等 · 找下降拐点、交换、反转后缀
- [287. 寻找重复数](../problems/0287-find-the-duplicate-number.md) · 中等 · Floyd 快慢指针映射成环

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
