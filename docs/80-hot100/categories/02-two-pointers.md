# 双指针：4题

双指针的关键不是两个变量，而是移动一端为什么能安全排除一批候选。相向指针依赖排序或支配关系，同向指针常维护稳定压缩的已处理前缀。

## 本类题目

- [283. 移动零](../problems/0283-move-zeroes.md) · 简单 · 快慢双指针原地压缩
- [11. 盛最多水的容器](../problems/0011-container-with-most-water.md) · 中等 · 相向双指针：移动较短的一边
- [15. 三数之和](../problems/0015-3sum.md) · 中等 · 排序、固定一个数、双指针并去重
- [42. 接雨水](../problems/0042-trapping-rain-water.md) · 困难 · 双指针维护左右最高柱；前后缀最大值作入门版

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
