# 贪心算法：4题

贪心必须给出安全性证明：交换论证、支配关系或当前层最远可达。只说“每次选最大”不足以说明正确。

## 本类题目

- [121. 买卖股票的最佳时机](../problems/0121-best-time-to-buy-and-sell-stock.md) · 简单 · 维护历史最低价与最好利润
- [55. 跳跃游戏](../problems/0055-jump-game.md) · 中等 · 维护当前最远可达下标
- [45. 跳跃游戏 II](../problems/0045-jump-game-ii.md) · 中等 · 维护当前层边界与下一层最远位置
- [763. 划分字母区间](../problems/0763-partition-labels.md) · 中等 · 字符最后位置与贪心分段

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
