# 图论：4题

把节点、边、访问状态说明白，再决定DFS、BFS还是拓扑排序。多源BFS是从所有初始源同时扩散；前缀树是按字符边组织检索状态。

## 本类题目

- [200. 岛屿数量](../problems/0200-number-of-islands.md) · 中等 · 显式栈 DFS 或队列 BFS 标记连通块
- [994. 腐烂的橘子](../problems/0994-rotting-oranges.md) · 中等 · 多源 BFS 按层扩散
- [207. 课程表](../problems/0207-course-schedule.md) · 中等 · 入度表与拓扑排序
- [208. 实现 Trie (前缀树)](../problems/0208-implement-trie-prefix-tree.md) · 中等 · 字典子节点实现 Trie，并区分终止标记

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
