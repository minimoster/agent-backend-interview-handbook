# 栈：5题

普通栈记录尚未匹配或暂停的上下文，单调栈记录还没找到边界的候选。先解释弹出时算出的是什么，再写while。

## 本类题目

- [20. 有效的括号](../problems/0020-valid-parentheses.md) · 简单 · 栈匹配最近的未闭合括号
- [155. 最小栈](../problems/0155-min-stack.md) · 中等 · 数据栈与最小值栈
- [394. 字符串解码](../problems/0394-decode-string.md) · 中等 · 计数与字符串上下文栈
- [739. 每日温度](../problems/0739-daily-temperatures.md) · 中等 · 单调栈保存待求解下标
- [84. 柱状图中最大的矩形](../problems/0084-largest-rectangle-in-histogram.md) · 困难 · 单调栈在出栈时计算最大矩形

## 学完后自检

- 能说出每题结构里保存的是什么，而不只是背容器名称。
- 能解释每次丢弃候选、移动边界或改变状态为什么安全。
- 能写出最容易出错的最小输入，并说明预期输出。
