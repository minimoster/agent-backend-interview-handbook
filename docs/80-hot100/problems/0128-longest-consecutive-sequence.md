# 128. 最长连续序列

难度：MEDIUM · 分类：哈希

## 题意与接口

在无序整数数组中寻找由连续整数构成的最长序列长度，元素在原数组中不必相邻。`longestConsecutive(nums)` 返回长度，不修改输入。

## 从朴素方法到优化

排序去重后线性扫描需 O(n log n)。直接从每个数向右找会在长连续段上重复走 O(n²)；只从没有前驱的数启动即可消掉重复。

## 核心思路

先转为集合。如果 x-1 在集合里，x 不是段起点，跳过；否则依次查 x,x+1,…直到断开，并更新段长。

## 手推一个小例子

[12,9,3,10,11,9]去重后有{3,9,10,11,12}。3没有2，走一格；9没有8，走9→10→11→12共四格；10、11、12都有前驱，不再启动。

## 为什么正确

每个有限连续段都有唯一最小值，它没有前驱，因此该段必被扫描一次。非起点被跳过不丢失任何段。每个集合元素至多属于一次向右扩张，总扫描量线性。

## Python 实现

[完整可导入源码](../../../examples/hot100/p0128_longest_consecutive_sequence.py)。节点结构来自 [structures.py](../../../examples/hot100/structures.py)；普通题使用 `Solution`，设计题使用题目类名。提交到 LeetCode 时保留算法主体，删除本地节点导入，使用平台提供的节点类型。

```python
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        # 去重既保证段长正确，也避免重复的起点多次扫描。
        values = set(nums)
        best = 0
        for value in values:
            if value - 1 in values:
                continue  # 只在连续段最左端起跑
            end = value
            while end in values:
                end += 1
            best = max(best, end - value)
        return best
```

## 复杂度

设 n 为输入长度，u 为不同值个数。平均时间 O(n)，空间 O(u)；虽然有嵌套循环，内层累计只访问每个连续段一次。

## 边界与易错点

- 空数组返回0；重复值不增加长度。
- 必须遍历去重集合，否则重复的段起点可能重复长扫描。
- 连续的是数值，不是原数组下标。
