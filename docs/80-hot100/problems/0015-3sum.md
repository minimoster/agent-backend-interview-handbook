# 15. 三数之和

难度：MEDIUM · 分类：双指针

## 题意与接口

返回数组中三个不同位置组成、值之和为零的所有不重复三元组。`threeSum(nums)` 返回三元组列表；本实现复制排序，不修改输入。

## 从朴素方法到优化

三层枚举为 O(n³)，还要去重。先排序并固定最左元素后，剩下变成有序数组的两数和，可用相向指针把每轮降到 O(n)。

## 核心思路

固定索引i；和偏小就增大左指针，和偏大就减小右指针。固定值重复时跳过，找到一组后同时跨过相同左右值，避免相同值组合重复出现。

## 手推一个小例子

[-3,1,2,2,0,-1]排序为[-3,-1,0,1,2,2]。固定-3，-1+2太小；0+2仍小；1+2恰好，记[-3,1,2]并跳过重复2。固定-1时得到[-1,0,1]。

## 为什么正确

有序性保证和小于零时，当前左值与任何更小的右端均不可能达标，所以左移到下一个值安全；和过大时对称。每个三元组唯一对应一个固定最小值，分层去重使其恰记录一次。

## Python 实现

[完整可导入源码](../../../examples/hot100/p0015_3sum.py)。节点结构来自 [structures.py](../../../examples/hot100/structures.py)；普通题使用 `Solution`，设计题使用题目类名。提交到 LeetCode 时保留算法主体，删除本地节点导入，使用平台提供的节点类型。

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        values = sorted(nums)
        answer = []
        for i in range(len(values) - 2):
            if i and values[i] == values[i - 1]:
                continue
            if values[i] > 0:
                break
            # 固定最小值后，剩余二元组可借有序性单调移动。
            left, right = i + 1, len(values) - 1
            while left < right:
                total = values[i] + values[left] + values[right]
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    answer.append([values[i], values[left], values[right]])
                    low, high = values[left], values[right]
                    while left < right and values[left] == low:
                        left += 1
                    while left < right and values[right] == high:
                        right -= 1
        return answer
```

## 复杂度

时间 O(n²)，排序副本与Python排序辅助空间 O(n)，输出空间 O(r)，r为三元组个数。不能把使用sorted的实现记成O(1)辅助空间。

## 边界与易错点

- [0,0,0,0]只能输出一个[0,0,0]。
- 指针必须满足left<right，不能重复使用一个位置。
- 去重针对值组合，不是把原输入简单set化。
