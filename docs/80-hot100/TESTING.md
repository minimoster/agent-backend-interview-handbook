# 本地测试、约束核对与验证边界

[返回100题导航](README.md) · [最新验证记录](validation-result.json)

## 一条命令完整复现

从仓库根目录执行，Python 3.10+，仅依赖标准库：

```bash
python -B examples/hot100/run_validation.py
```

该命令运行完整性检查与全部单元测试，并更新 `docs/80-hot100/validation-result.json`，记录实际Python版本、测试入口数量、失败项及每题源码SHA-256。运行结果以当前报告和退出码为准，退出码0表示这套本地检查通过。

也可以拆开运行：

```bash
python -B -m unittest discover -s tests/hot100 -p 'test_*.py' -v
python -B examples/hot100/check_hot100.py
```

## 测什么

- 每题至少一个含题号的测试方法，对应100个不同题号；多数测试方法循环运行多个边界输入与随机输入。
- [数组/窗口/矩阵](../../tests/hot100/test_arrays_windows_matrix.py)：21题。小规模枚举和区间参考实现；检查原地操作返回值、稳定顺序、输入是否按契约保持不变。
- [二分/栈/堆](../../tests/hot100/test_search_stack_heap.py)：14题。二分对照bisect或扫描，括号对照独立消除法，矩形对照区间枚举，双堆对照已排序中位数；215同时验证Quickselect与堆实现。
- [链表/树/图/回溯](../../tests/hot100/test_structures_algorithms.py)：41题。检查节点身份、深拷贝、原链恢复、原地重连；图遍历使用独立参考法；回溯输出按集合/合法性核验，避免依赖答案顺序。
- [贪心/DP/技巧](../../tests/hot100/test_greedy_dp_tricks.py)：24题。独立穷举、二维DP、排序或集合等参考法核验最优值与状态转移；原地题检查修改结果。
- 深度与规模边界包括30000节点退化树最大路径和、3000节点树重建/展开、300×300连通岛屿。它们检查选定实现的实际边界行为，并非通用性能基准。

随机测试使用固定种子，失败输入可复现。小输入随机对拍擅长发现边界和状态更新错误，但不能证明全部输入正确；正确性仍需要每题的不变量或递推论证。

## 可选：五道高风险题的有限穷举

```bash
python -B tests/hot100/exhaustive_checks.py
```

[扩展检查记录](exhaustive-result.json)记录84、41、76、4、215共159709组有限域输入；215每组同时验证Quickselect与堆。参考答案分别来自区间枚举、值存在性、子串枚举、排序后的中位数与名次。还检查承诺不修改输入的算法是否保持输入不变。

这个数字表示指定有限域内的输入组合数，不是覆盖率百分比；包含明确的本地扩展输入，例如空数组或多个同长最短窗口。它并不穷尽官方全部约束范围。

## 静态完整性检查

`check_hot100.py`检查：

1. 100个不同题号、100个不同slug、17个官方分类；分类顺序与逐题顺序一致。
2. 每题恰有一份讲解和一份实现，没有缺题或额外题冒充Hot100。
3. 每页具备10个教学段落、正确官方链接，Python代码块与实际源码逐字一致（忽略源码首行标题docstring）。
4. 所有模块语法有效，普通题和设计题类名符合统一接口。
5. 模块内Markdown相对链接目标存在，每题有测试入口。

本地链接检查不等于对第三方网站可用性的永久承诺。外链可能在未来迁移，官方题单也可能调整，核验日期是版本背景的一部分。

## 官方契约核对

题单和分类以2026-10-09中国站官方学习计划为准。逐题题页核对记录分为：

- [35题数组/窗口/二分/栈/堆](../../sources/hot100-core-page-checks.json)
- [41题链表/树/图/回溯](../../sources/hot100-structures-page-checks.json)
- [24题贪心/DP/技巧](../../sources/hot100-greedy-dp-page-checks.json)

记录的是实际读取的官方题目语义和关键约束，不复制完整题面。部分首次读取超时后使用官方 `/description/` 页面或对应英文官方页成功读取。平台提供的Python节点类在本地由 `structures.py`替代；提交适配说明见[接口说明](../../examples/hot100/README.md)。

一些测试刻意包含空输入等题设外边界，验证的是页面明确说明的本地扩展行为。不要由这些额外用例推断所有题都接受所有非法输入。例如第17题当前官方约束为非空digits，本地空字符串返回空列表是额外便利行为。
