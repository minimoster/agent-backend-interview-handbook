# 四个小实验：把答案变成自己的理解

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md) · [版本与纠错](../../errata/README.md)

- **取消实验** ：写 producer/worker/consumer；让 consumer 提前结束，观察未处理取消时谁卡住。修复后用测试证明所有 worker 返回。
- **切片实验** ：改变初始 cap，分别观察 append 前后两个 slice 是否共享；画出长度、容量与底层数组，不只背打印结果。
- **流式实验** ：使用本地假模型逐段返回，测试正常、首段慢、半途失败、用户断连和慢读者；记录任务是否取消、G 是否回落。
- **性能实验** ：对同一 handler 保存一份基线，再做一个有依据的改动，测成功率、吞吐、P95/P99、B/op/allocs/op；保留命令、环境与样本，不挑最好看的一次。

验收标准：每题先用 30–60 秒讲主线，再接受 2–3 分钟追问；遇到未验证的版本细节能说“我会查该版本源码/文档”，比把旧口诀讲得很确定更可靠。
