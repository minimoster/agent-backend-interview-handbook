## R01 1000个候选中一个异常，二值测试需要多少位？

**优先级：P2。**

**知识点详解：** 假设恰有一个异常候选，每次测试只有0/1两种可靠结果，允许一个候选参与多个测试，而且一次并行测试后才读取结果。还需明确集合测试的响应规则：测试预先选择一个候选子集，结果为1当且仅当该子集包含异常候选；不包含则为0。推广到多个异常时，这相当于子集中异常成员的OR，没有抵消、相互作用或误报漏报。仅说“结果可靠且二值”并不能推出这个成员响应模型。

k个测试的结果向量最多有2的k次方种，因此区分1000种情况至少要10位：9位只能512种，10位可1024种。这个计数是信息容量的下界；按位分组的构造可达到下界，依赖上面的子集成员/OR规则。

**具体例子：** 将1000个候选编号0至999，写成10位二进制。第i个测试包含编号第i位为1的候选；结果中哪些位为1，就还原异常编号。如果使用0号，全部为0对应0号异常，而不是“没有异常”；这依赖“恰有一个”的前提。若还允许不存在异常，可以使用1至1000编码，把全零留给“无异常”。

**面试答法：** “先看一次测试能区分几种结果。10个二值结果有1024种状态；我给候选唯一10位编码，并按位设计集合测试，因此既有下界又有构造。”

**追问：** 两个异常会怎样？按位OR可能产生同一结果，原编码不能直接唯一解码。结果有噪声呢？要冗余、重测和纠错设计，不能沿用无噪声下界作为可用方案。

**常见误区：** 没有说明是否恰好一个异常；把0号漏掉；允许多个异常却继续声称10次足够；把抽象模型当真实试验建议。

**验证：** 以上为独立信息容量推导。

## R02 5升和6升容器，怎样量出3升？

**优先级：P2。**

**知识点详解：** 题设允许从外部装满、清空，以及把一个容器倒到另一个满或自己空；容器没有刻度。用状态 `(五升容器, 六升容器)`，每步只做允许动作。不要说“倒出一半”，因为没有刻度且形状未给，无法保证等分。

**具体例子：** 一条可验证路径为：

```text
(0,0) → 装满五升 → (5,0)
→ 倒入六升 → (0,5)
→ 装满五升 → (5,5)
→ 倒满六升 → (4,6)
→ 清空六升 → (4,0)
→ 将四升倒过去 → (0,4)
→ 装满五升 → (5,4)
→ 倒满六升 → (3,6)
```

每次转移的水量是“来源现有量”与“目标剩余空间”的较小值。最后五升容器留下3升。因为允许丢弃与补水，总水量不守恒，但每个容器始终在0到容量之间。

**面试答法：** “我记录两个容器的水量，逐步制造差额；先得到4升，再让六升容器只差2升，用满五升补齐后剩3升。每一步都只倒到满或空。”

**追问：** 怎么找最少步？把合法状态视为图，动作都等价时BFS得到最少动作数；如果装水和倒水成本不同，应改加权最短路。

**常见误区：** 中途凭空得到已知水量；忽略容器容量；把一条成功路径称为唯一解。

**验证边界：** 本仓库BFS枚举并返回上面8个动作，在已声明动作模型下为最短步数。

## R03 10、7、3升容器，怎样把10升分成5和5？

**优先级：P2。**

**知识点详解：** 起始状态是 `(10,0,0)`，目标是 `(5,5,0)`；禁止外部补水或倒掉。这与上一题不同，总量始终为10。状态向量按10、7、3升容器排列。

**具体例子：**

```text
(10,0,0) → (3,7,0) → (3,4,3) → (6,4,0)
→ (6,1,3) → (9,1,0) → (9,0,1)
→ (2,7,1) → (2,5,3) → (5,5,0)
```

依次是：10→7，7→3，3→10，7→3，3→10，7→3，10→7，7→3，3→10。每次都倒到目标满或来源空。最后一步把3升还给10升容器，得到5和5。

**面试答法：** “我先确认不能丢水，用三元组记录状态并检查每步总量10。通过3升容器逐步制造1升余量，再让7升容器留下5升。”

**追问：** 为什么使用BFS而不是DFS找最少步？DFS先找到不一定最短，BFS按动作层数扩张。怎么避免循环？对已访问状态去重并保存前驱，而不是只记录当前容器。

**常见误区：** 把上一题可清空的动作带进来；路径中总水量突然减少；只说“反复倒”没有可复演序列。

**验证边界：** 在固定水量、满/空倒水模型下，BFS给出9个动作的最短路径。

## R04 7升和11升容器，怎样量2升，并把它写成通用算法？

**优先级：P2。**

**知识点详解：** 仍允许装满与清空。容量最大公约数是1，是用此类动作得到整数目标的必要可达性依据；但知道“能到”不等于已经给出操作路径。程序中每个状态只有有限个合法后继，适合BFS。

**具体例子：** 以 `(七升,十一升)` 表示：

```text
(0,0) → (7,0) → (0,7) → (7,7) → (3,11)
→ (3,0) → (0,3) → (7,3) → (0,10)
→ (7,10) → (6,11) → (6,0) → (0,6)
→ (7,6) → (2,11)
```

每次先装满7升，再向11升倒；当11升满则清空，将余量移入，重复后得到2升。实现通用转移时，i向j倒水量 `min(state[i], capacity[j]-state[j])`，同时减少i和增加j，不能只更新一边。

**面试答法：** “我用状态和合法动作建图，不凭感觉跳步骤。队列找到目标后沿前驱回溯路径，visited防止来回倒水造成循环。”

**追问：** 如果只求可达不求最短，搜索选择可以变；如果不许清空，状态图和可达性也变化。目标超过单容器容量时，要先确认允许把两个容器的总量算目标吗。

**常见误区：** 忘记BFS所证明的是特定动作计数下的最短，不是最少总耗水或最少实际时间。

**验证边界：** BFS在本题动作模型下找到14动作最短路径。实现与输出已提供。

## R05 4分钟和7分钟沙漏，怎样从开始时刻量9分钟？

**优先级：P2。**

**知识点详解：** 关键是翻转时剩余的沙量，而不是把沙漏名称当任意计时器。假定沙流均匀、翻转瞬时、可以同时启动，以开始为0分钟。

**具体例子：**

| 时刻 | 已发生事件 | 操作及剩余量 |
|---|---|---|
| 0 | 同时启动两只沙漏 | 分别剩4和7分钟 |
| 4 | 4分钟沙漏漏完 | 翻转4分钟沙漏 |
| 7 | 7分钟沙漏漏完 | 翻转7分钟沙漏，此时4分钟沙漏还剩1分钟 |
| 8 | 4分钟沙漏第二次漏完 | 7分钟沙漏仅流过1分钟，立即把它翻转，朝下的一侧只需再流1分钟 |
| 9 | 7分钟沙漏漏完 | 停止，从0到现在正好9分钟 |

第8分钟翻转后，剩余不是6分钟，而是刚流到下方的1分钟沙量。不能把“第7分钟后4分钟沙漏下次漏完”误算为第16分钟；它的真实事件在第8分钟。

**面试答法：** “我列0、4、7、8、9的事件轴。第8分钟把只流过1分钟的7分钟沙漏反过来，用这一分钟在第9分钟结束。”

**追问：** 如果题目允许先准备再开始测，可能有其他路径；必须说清起止点。翻转耗时或沙流不均匀时，这只是理想模型，不是精密测量方案。

**常见误区：** 不说从何时开始计9分钟；翻转未漏完沙漏后仍认为时长等于总容量；时间线自相矛盾。

**验证边界：** 独立推导时间线；程序逐事件核对了上方剩余沙量，最后时刻为9。

## R06 每根燃尽一小时的不均匀绳子，怎样计75分钟？

**优先级：P2。**

**知识点详解：** 本题允许若干根各自单端燃尽恰好60分钟的绳子，燃速沿长度不均匀；不允许靠剪成几何一半计30分钟。在理想燃烧模型中，同时点燃两端会让两条火线消耗同一根绳的全部“燃烧时间”，总耗时变为30分钟。

**具体例子：** 使用3根。时刻0同时点燃第一根两端和第二根一端；第一根在30分钟烧完。此时点燃第二根另一端，它原本还需单端烧30分钟，双端再烧15分钟，因此在45分钟烧完。此刻点燃第三根两端，30分钟后结束，即75分钟。

可用“剩余单端燃烧时间”理解，而不是观察剩余长度。第二根在30分钟时剩下的物理长度不一定一半，但其剩余单端时间确实30分钟。

**面试答法：** “先用双端燃烧得到30分钟，再把另一根剩余30分钟减半得到15分钟，最后用第三根双端增加30分钟，合计75。这里用3根，题目若限制两根，需要重新讨论，不能偷偷增加材料。”

**追问：** 两端燃烧为何成立？必须假定火焰传播行为独立且同一点火燃烧特性不因方向等外界因素变化；这是题目的理想规则，不能作为现实精确计时承诺。

**常见误区：** 按绳长切分时间；没声明用3根；在没有已知计时事件时凭空说“等15分钟”。

**验证边界：** 已核对所读题目允许若干根、原方案用3根；以上为独立时间推导，未进行任何真实点火实验。

## R07 25匹马、5赛道，怎样确定有序前三，并说明为什么6场不够？

**优先级：P2。**

**知识点详解：** 本节明确要求确定第一、第二、第三名及其顺序。假设每场最多5匹、速度恒定、没有并列、不计绝对时间，只知道场内名次。先给7场构造，再证明这一有序前三模型的最少场数；如果题目只要无序三匹集合，不能省略确认任务定义，本节不另宣称已证明该不同问题的全局下界。

**具体例子：** 分5组各跑一次，共5场，组内记A1快于A2快于……。第6场让各组第一比赛，按结果重新命名使A1、B1、C1、D1、E1依次排名。A1是全局第一。还能争第二第三的只剩A2、A3、B1、B2、C1，第7场让这5匹跑，前两名加A1即答案。

排除理由：A4前面已有A1/A2/A3；B3前面已有A1/B1/B2；C2前面已有A1/B1/C1；D1前面已有A1/B1/C1，因此它们都不可能前三。这是利用已知偏序消除候选。

**6场不够的最坏情况对抗思路：** 25匹最初都可能是第一。为构造一个困难但相容的结果分支，只要比赛中还有未输过的候选，对手就让其中一匹获胜，其余顺序保持与已知比较相容；未输者没有已知更快者，因此这种选择可扩展为一个固定速度全序。在这个分支中，一场至多淘汰4名第一候选；若混入已输马，则参赛的未输者至多4匹，且其中仍有一匹获胜，这场最多淘汰3名候选。6场若要从25个第一候选缩到1个，就必须每场淘汰4个，故这个困难分支里的每场都要由5匹未输者组成。至少有一匹此前赢过的马必须出现在最后决定冠军的比赛中；对手让它再次获胜。把该冠军早先一场的第二、第三名记为u2、u3，最后一场的第二、第三名记为v2、v3。已知两条链“冠军快于u2快于u3”和“冠军快于v2快于v3”，但两链之间没有比较：前面已输过的马不能再参赛，否则无法在6场内完成24次最大候选消除。仍可能存在两个都满足全部结果的速度全序，一个前三集合为{冠军,u2,u3}，另一个为{冠军,v2,v3}。所以不只是第二第三的内部次序未知，连前三匹的集合也无法保证确定。因此6场无法保证本题要求的有序前三，7场构造达到下界。两条链同时说明这个最坏分支连前三集合也不明，但下界的候选消除开头依赖“必须确定冠军”的有序任务要求；不能据此省略对无序版本的另行论证。

**面试答法：** “5场组内排序，1场组首排序，再跑A2/A3/B1/B2/C1。先用已知至少三匹更快排除其余候选；最少场数需附下界，不能只报7。”

**追问：** 有计时器且环境可比时，可能只需分组测速度，题目本质变化。存在并列时“前三匹”与“前三名”也不同。

**常见误区：** 只比较每组第一就得前三；把小组第二全部排除；认为随机模拟就是最优性证明。

**验证边界：** 构造和排除/下界解释为独立推导，10000个全序模拟未发现构造反例。模拟不承担下界证明。

## R08 64匹马、8赛道找前四，“11场最少”能直接相信吗？

**优先级：P2。**

**知识点详解：** 假设与上一题相同，只把规模改为64匹、每场8匹、求前四。本章给出至多11场的可行方案，不把它冒充已证明的全局最少。所读材料缺少对应最优下界，不能只沿用数字。

**具体例子：** 先8组各跑一次，再让8个组首跑第9场，按组首顺序命名A至H。A1为全局第一。除A1外，候选只有A2/A3/A4、B1/B2/B3、C1/C2、D1，共9匹。因为位于第i组第j名的马，至少有i+j-2匹确定比它快，只有i+j不大于5还可能进前四。

第10场先跑除A4之外的8匹，记其前三名。如果前两名不是A2和A3（按它们原有顺序），A4前面除了A1/A2/A3，至少还能找到一匹更快，不能进前四；直接取第10场前三加A1即可。如果前两名恰好A2、A3，则最后一个名额在A4与第10场第三名之间，第11场比较它们即可。不能不分析条件就任意删除B3或另一个候选。

**面试答法：** “我能构造最坏11场的策略，并说明第11场何时必要于这条策略。但这不等于所有可能策略最少都是11场；缺全局下界时我会区分上界和最优解。”

**追问：** 如何证明全局最优？需要对允许的自适应比赛决策建立下界或完整搜索证据，不能用对自己方案的局部反例替代。一个分支10场结束，也不说明最坏情况10场足够。

**常见误区：** 将上界写成最小值；一次性9匹放进8赛道；根据未知的跨组相对速度丢弃候选；把随机试验通过当成最优证明。

**验证边界：** 以下为原创条件策略，10000个全序模拟通过。**全局最优场数未在本讲义证明。**

## R09 海盗分100枚金币，为什么97和98都可能出现？

**优先级：P2。**

**知识点详解：** 五人按资历提案，否决则提案人出局，剩余者继续。必须先定义：提案人是否投票、赞成达到一半还是严格过半、同样金币时是否倾向否决，以及生存与钱哪个优先。下面明确每人优先活着、其次多钱、钱一样时愿意否决；提案人有一票。

**具体例子：** 若“赞成至少一半”即通过，逆推1人拿100；2人提案者一票就够，可拿100/0；3人买到末位原本0币的票，要给1币；逐层得到五人分配 `98,0,1,0,1`。若改成“严格超过一半”，两人时提案人无法让对方拿到超过独占100的收益，会被否决；三人可用生存买到下一位本来会死者的票。继续逆推，五人可以分配 `97,0,1,2,0`，也存在对称的等价选择。

逆推的是“如果现在否决，下一局各人会怎样”，不是凭直觉平均分。严格过半模型中的0币也可能买到一票，因为对方首先在乎活着。

**面试答法：** “我先固定投票门槛和偏好，再从一人倒推。不同门槛得到不同最低购票成本，因此题设没讲清时不能断言提案者一定拿97。”

**追问：** 如果同收益时愿意赞成，需要的最小增量会变；允许结盟或不同风险偏好也会改变模型。数学理性假设不代表真实人的必然行为。

**常见误区：** 忽略自投票；把至少一半与严格过半混用；把死者的收益与活着0币等同；只背结果不讲续局。

**验证边界：** 程序按两套明确规则独立逆推，得到上述分配。不声称题设缺失时有唯一答案。

## R10 七天工资用金条支付，为什么1、2、4需要允许找零？

**优先级：P2。**

**知识点详解：** 一根7单位金条，第d天结束时员工累计持有d单位。允许把已付的金条收回找零，切两次得到1、2、4三块。每天员工持有的块组合表示0到7的任意整数，这正是三位二进制。

**具体例子：** 每天结束员工持有：第1天1；第2天2（换回1）；第3天1+2；第4天4（换回1和2）；第5天4+1；第6天4+2；第7天全部。题目限制的是累计净持有量，不是每次只能单向交付一块。

三块有8种子集，足以覆盖0至7；只有两块最多4种子集，无法形成8种每日累计状态，所以在这一模型下至少三块，即至少两次切割。若不能收回找零，1/2/4方案就不满足每天准确新增1单位。

**面试答法：** “先确认允许找零，再用1、2、4的子集表示每日累计额；两块的可表示状态太少，因此三块是必要的。”

**追问：** 15天可以用1、2、4、8；如果某些天不用支付或允许欠账，需要重新定义需覆盖的集合。

**常见误区：** 没问能否找零；混淆切割次数与块数；把累计工资和当天交付物简单等同。

**验证边界：** 程序枚举三个块的全部子集，结果恰好为0至7。

## R11 五人顺序取100颗豆，最多和最少者淘汰，谁最安全？

**优先级：P2。**

**知识点详解：** 给定规则只有每人至少取1、可知道袋中剩余数、不能交流，还不足以推出某个位置更安全。需进一步明确并列最大/最小是否全淘汰，必须不必须取完，参与者追求确定生存还是最大生存概率，以及对别人策略有什么信息。

**具体例子：** 若五人都取20，且并列最多与最少者都淘汰，那么全员都处于两个极值，可能全淘汰；若并列时另抽签，结论不同。若后几个人可以不取尽，最后一人也不一定被迫拿剩余所有豆。没有随机选取规则或概率分布，就不能给出“第一人存活率最高”的数值概率。

合理作答流程是把这些缺口问清，再枚举小规模版本或做逆向推导。例如先把总量改成10、人数3，写出完整终局得分和合法动作，观察是否存在纯策略均衡，再讨论更大问题。模拟任意随机策略只能说明那种策略假设下的结果，不是本题答案。

**面试答法：** “这道题目前不够确定。我先确认并列、取尽和偏好规则；全取20是否全员出局都由规则决定。没有随机模型时我不会把策略推测说成存活概率。”

**追问：** 面试官不补规则怎么办？可以明确声明一组假设并在它下面推导，同时承认不是所有解释的唯一解。

**常见误区：** 从一个失败例子跳到第一人必胜；把摸剩余数当能知道每位此前选择；没有概率空间就比较概率；掩盖题设自相矛盾。

**验证边界：** 已核本题条件关键条件；本题结论是规则不足，未伪造均衡解或实验概率。

## R12 20元汽水、2空瓶换1瓶，到底39还是40瓶？

**优先级：P2。**

**知识点详解：** 每瓶1元，先买20瓶。喝一瓶得到一空瓶，交2空瓶换1瓶、喝完又得到1空瓶，所以每多喝一瓶兑换汽水，手中空瓶净减少1。若不能借瓶或赊账，从20个空瓶出发，最终至少留1个不能继续兑换的空瓶，因此最多再换19瓶，总计39。

**具体例子：** 按批兑换：20空瓶→喝10瓶并留10空瓶→喝5并留5→喝2并留3→喝1并留2→喝1并留1。新增10+5+2+1+1=19。

若店家明确允许借一空瓶并在兑换后归还，可在剩1空瓶时借1、换1瓶并喝完，再把新空瓶归还，于是多1瓶成为40。这个步骤是额外的信用条件，题目不允许时不能自行加入。“可以兑换”本身并不隐含“可以先借”。

**面试答法：** “无借瓶时39，有借一空瓶并归还的规则才是40。用空瓶净减少1的守恒关系说明，比无限写兑换过程更清楚。”

**追问：** 3空瓶换1时每次净减少2；是否可借多少以及最终必须归还多少，决定能否补足最后一次交换。若瓶盖也能换，要同时跟踪两类资源，原一维守恒不够。

**常见误区：** 把题面没有的借瓶当默认；兑换时忘记喝完会产生新空瓶；无限循环兑换却不检查资源减少。

**验证边界：** 本题未允许借瓶；程序递推无借瓶规则得39并剩1空瓶，40被明确列为附加规则下的答案。
