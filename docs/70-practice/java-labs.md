# 练习顺序与自测

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md) · [版本与纠错](../../errata/README.md)

第一遍先完成 J01–J05、J09–J16、J18、J23–J24、J27–J28、J30、J32–J35、J37–J45。每题必须能回答“它解决什么问题”“失败会怎样”“我怎样验证”，之后再补 P1/P2。

三个最值得亲自做的小实验：

- 两线程各自执行十万次普通 count++，与 AtomicInteger 对比，并解释为什么偶尔得到正确值不能证明安全。
- 建一个核心 2、最大 4、队列 2 的有界线程池，用受控阻塞任务验证提交路径、拒绝与取消，不要以真实付费模型当压测目标。
- 对同类调用与跨 Bean 调用的事务各写回滚测试，故意让第二次写入失败，再独立查询数据库验证结果。

面试表述底线：示例中的并发量、超时、延迟都只是教学假设；只陈述你亲自实现、复现或测量过的部分。没有真实压测就说“我会这样验证”，不要说“我优化了 80%”。
