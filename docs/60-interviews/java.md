# Java 综合训练

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md)

把语言、集合、并发、JVM与项目串起来。每组先回知识章节理解答案，再用一个例子与一个失败反例练口述；实现细节按实际JDK与框架版本核对。

## 1. Bean、线程池与JVM

问题：Bean生命周期怎样展开？线程池参数、排队与拒绝策略如何配合？JVM有哪些运行时数据区？模型输出又怎样传到前端？

解析与练法：项目、基础与算法一起准备。分别画Bean创建边界、请求排队及流式接口的状态图。

## 2. 集合、CAS与项目容量

问题：HashMap与ConcurrentHashMap怎样定位元素并处理并发？CAS、synchronized与GC各解决什么？

解析与练法：解释容量、负载因子、扩容、并发访问与ABA，再给项目数据规模和读写分布。阈值与分库分表条件不能只背一个固定数字。

## 3. 线程协调、GC与类加载

问题：CountDownLatch与CyclicBarrier如何区分？多个线程何时可继续？集合、GC与类加载怎样关联对象生命周期？

解析与练法：把一次性等待与可复用屏障分开，补超时、异常和退出路径；版本细节按当前项目核对。

## 4. 通用后端机制

问题：线程与协程、Redis、SQL、Kafka及算法怎样与Java服务连接？

解析与练法：语言之外仍要说明数据库事务、消息确认、缓存失效和网络超时的边界，不让一个框架名称代替机制。

## 5. 项目、表设计与测试部署

解析与练法：第一次实习也可从目的、实现、测试与部署记录展开回答。给出自己能解释的代码、实际运行结果及未

## 6. 跨主题追问

问题：集合、CAS/ABA、类加载、事务与限流怎样共同影响一条请求？

解析与练法：沿请求入口找共享状态、资源等待与提交边界，用反例发现薄弱点，再回对应章节补机制。

## 7. Agent应用的Java底座

问题：Java、Spring Boot、数据库、缓存、网络、Git/Docker怎样承载Agent接口？个人项目里哪些功能由AI辅助，哪些由自己验证？

解析与练法：先守住后端基础，再说明模型调用、状态和权限；不把某一项目的设计推广成所有岗位的要求。

## 8. IoC与执行资源

问题：集合、事务、IoC、类加载和线程池分别在哪个边界生效？

解析与练法：先解释容器管理的对象，再画调用路径与资源归属；将排队、线程占用和数据库连接预算一起讨论。

## 9. 代理与事务自调用

问题：代理如何拦截方法？同一个Bean内部自调用会怎样影响事务注解？

解析与练法：区分调用是否经过代理、外层是否已有事务、传播行为与异常规则；不要把“被调用注解未生效”说成“一定没有任何事务”。
