# 真实公开面经样本

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md) · [版本与纠错](../../errata/README.md)

以下两篇是可公开访问、带日期的个人面试自述。能核验的是帖子内容与显示日期，不能独立证明面试过程、录用结果或公司通用标准。仅摘取少量主题，不复制整篇，也不采用帖内回答作为技术权威。

- **[BE01](../../sources/catalog.md#be01) 字节后端实习一面，2025-06-02。** 作者“牛客832470130号”。帖子涉及数据库索引、事务隔离、Redis 数据结构与缓存异常、分布式锁和 Go 并发。对应本篇 B09—B18、B22—B30。准备启发：基础概念会与项目架构一起被问，不能只背语言语法。[原始公开帖](https://www.nowcoder.com/feed/main/detail/e9e3240692f647deacd85b854fcc1ca3)
- **[BE02](../../sources/catalog.md#be02) 最右后端暑期实习，页面显示 2025-04-22 已编辑。** 作者“想开了的沸羊羊很想拿”。自述包含 HTTP、数据库隔离、回表、缓存取舍，以及围绕聊天项目的连续追问。对应 B05、B10、B14、B22、B31。准备启发：要解释为什么选某方案，以及消息丢失、数据增长后怎么办。[原始公开帖](https://www.nowcoder.com/feed/main/detail/44eeda0f5544458daf9efbd95f773cbe)

本篇 B01—B50 是基于官方资料重新组织的原创学习题，不声称是上述公司逐字真题。两个样本不足以计算出题概率，也不能据此判断某家公司一定考或一定不考某技术。
