# Agent 综合训练

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md)

从问题出发，连接原理、实现与验收。回答中分清个人工作、教学方案和已经运行的结果。

## 训练1：项目边界与评测质量

问题范围：由两个项目切入，追问 AI 生成代码与个人工作的边界、模型适配、工具定义和记忆；特别检查评测数据是否过小或泄漏；后段仍问 Redis、IO 和数据库。

解析与练法：准备一份“我能解释的核心函数 + 自己的改动 + 验证证据”，以及如何解释过高的测试命中率。

## 训练2：工具、记忆与RAG链路

问题范围：围绕工具接口、短长期记忆、Agent 架构选择与 RAG 链路展开，再问故障处理和调用成本。

解析与练法：不要只说“做了 RAG”，要讲参数依据、失败样例和排查顺序。

## 训练3：检索消融与项目取舍

问题范围：集中追问评测集质量、混合召回、排名融合及重排的选型依据，还要求解释两个项目的本质区别。

解析与练法：为 Saber 准备一个检索消融实验，比较向量、关键词、融合和重排；记录实验配置、结果与待验证项。

## 训练4：异步任务、事件流与业务状态

问题范围：从消息队列请求关联、认证和流式展示，延伸到 Agent 编排、记忆与 SSE，也包含缓存、容器和算法。

解析与练法：Agent 实习仍可能是后端工程岗位；必须解释异步任务 ID、事件流和真实业务状态的关系。

## 训练5：上下文压缩与Coding Agent

问题范围：重点是会话、token 估算、压缩后的信息保真、能力加载和子 Agent；手撕涉及嵌套 JSON 的递归处理，另有操作系统与数据库基础。

解析与练法：能够“解释如何压缩”还不够，要回答“如何证明没把约束压掉”；编程练习要覆盖嵌套结构和边界值。

## 训练6：运行时定制与数据分析Agent

问题范围：追问 runtime 定制、上下文和同步异步机制、改动的回归验证，再设计数据分析 Agent，并检查服务排障和后端基础。

解析与练法：作为进阶追问使用，首份实习优先掌握基础机制与可运行代码。

## 训练7：工具恢复与后端手写

问题范围：工具失败恢复、规模化场景、Go 并发和算法同时出现。提醒你保留后端及手写能力的备考时间。

## 训练8：记忆容量与上下文预算

问题范围：从 RAG 选型与切块转向长期记忆容量、历史原文保存和上下文限制。可练“存得下”和“放得进模型”是两个问题。
