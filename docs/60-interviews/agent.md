下面按公开作者的自述整理问题与学习提示。日期按原页记录，页面未给出年份或岗位地点时保留缺项；面试过程尚未获独立核实。

### 记录 1：安软 AI 应用开发实习

- 来源：[安软｜AI 应用开发实习面经](https://www.nowcoder.com/feed/main/detail/40920533fad14136bff01c3928c7e953)，作者 GdAfterN；页面显示 08-05 15:21，面试日期正文明确写为 2026-07-25。
- 证据：完整正文，个人账号的面试记录；约 28 分钟等信息是作者报告，未经独立核实。
- 摘要：由两个项目切入，追问 AI 生成代码与个人工作的边界、模型适配、工具定义和记忆；特别检查评测数据是否过小或泄漏；后段仍问 Redis、IO 和数据库。
- 练习建议：准备一份“我能解释的核心函数 + 自己的改动 + 验证证据”，以及如何解释过高的测试命中率。来源 ID：[AG-I01](../../sources/catalog.md#ag-i01)。

### 记录 2：字节 AI 应用开发一面

- 来源：[字节跳动 AI 应用开发一面面经](https://www.nowcoder.com/feed/main/detail/15af3788a038477bba99f2f9d94b2cef)，作者“私底下内向”；页面 08-10，正文称 8 月 6 日面试，年份均未明示。
- 证据：完整正文，有个人面试体验及实习标签；部门、真实录用结果未获验证。
- 摘要：围绕工具接口、短长期记忆、Agent 架构选择与 RAG 链路展开，再问故障处理和调用成本。
- 练习建议：不要只说“做了 RAG”，要讲参数依据、失败样例和排查顺序。来源 ID：[AG-I02](../../sources/catalog.md#ag-i02)。

### 记录 3：字节 Agent 开发后端日常实习

- 来源：[字节 Agent 开发后端日常实习一面凉面](https://www.nowcoder.com/discuss/932295617999622144?sourceSSR=home)，作者“溯洄之洲”；页面 09-24 已编辑，正文记面试日 09-23，未显示年份。
- 证据：完整正文，作者另有后续评论；其对拒绝原因的猜测不纳入结论。
- 摘要：集中追问评测集质量、混合召回、排名融合及重排的选型依据，还要求解释两个项目的本质区别。
- 练习建议：为 Saber 准备一个检索消融实验，比较向量、关键词、融合和重排；记录实验配置、结果与待验证项。来源 ID：[AG-I03](../../sources/catalog.md#ag-i03)。

### 记录 4：字节后端，大模型安全方向实习

- 来源：[字节后端（大模型安全）实习一面](https://www.nowcoder.com/feed/main/detail/6c8dcb6a6c8b49f1aecb5ba978b8a480)，作者“小牛油等一个offer”；页面 03-29 22:29，年份与面试日未单列。
- 证据：完整正文，第一人称体验。
- 摘要：从消息队列请求关联、认证和流式展示，延伸到 Agent 编排、记忆与 SSE，也包含缓存、容器和算法。
- 练习建议：Agent 实习仍可能是后端工程岗位；必须解释异步任务 ID、事件流和真实业务状态的关系。来源 ID：[AG-I04](../../sources/catalog.md#ag-i04)。

### 记录 5：字节 Agent 日常实习，Coding Agent 项目

- 来源：[字节 Agent 开发日常实习一面](https://www.nowcoder.com/feed/main/detail/d2cf5165d1184b59879eff5793b7b453?sourceSSR=subject)，作者“htt键盘手”；页面 08-27 20:11 已编辑，年份未显示。
- 证据：完整正文；有读者询问是否在别的平台发布，不据此断言原创或转载。
- 摘要：重点是会话、token 估算、压缩后的信息保真、能力加载和子 Agent；手撕涉及嵌套 JSON 的递归处理，另有操作系统与数据库基础。
- 练习建议：能够“解释如何压缩”还不够，要回答“如何证明没把约束压掉”；编程练习要覆盖嵌套结构和边界值。来源 ID：[AG-I05](../../sources/catalog.md#ag-i05)。

### 记录 6：字节飞书多维表格 AI 应用工程师

- 来源：[字节/AI 应用工程师一面挂经](https://www.nowcoder.com/discuss/933023499399024640?sourceSSR=dynamic)，作者 Wood555；页面 09-25 已编辑，未显示年份。
- 证据：完整正文，作者描述约 70 分钟视频面；带秋招标签，不能称为已确认实习面经。
- 摘要：追问 runtime 定制、上下文和同步异步机制、改动的回归验证，再设计数据分析 Agent，并检查服务排障和后端基础。
- 练习建议：作为进阶追问使用，不按这篇的深度给首份实习设置全部门槛。来源 ID：[AG-I06](../../sources/catalog.md#ag-i06)。
