# Go 综合训练

[返回总目录](../../README.md) · [题目索引](../../QUESTION_INDEX.md)

沿“项目数据流→Go机制→错误处理”练习。语言语义、运行时实现与具体版本分开说明。

## 训练1：map、channel与项目数据流

问题范围：从 Agent/RAG 的数据切片切入，检查 map 并发、channel 关闭、闭包和排错。另有短链接项目与容器构建讨论。

解析与练法：G03、G05、G14、G22、G39。特别值得练“项目中的数据流→相关 Go 原理→错误处理”，避免项目和基础各说各话。

## 训练2：并发池与性能观测

问题范围：项目深挖关注设计取舍、流量、耗时观测、第三方接入和 goroutine 池；Go 部分包含并发模式、channel 注意事项，另考网络和算法。

解析与练法：G04、G10、G27、G38–G40。启示是简历写“性能优化”就要能说明基线、负载和指标；练习时记录自己的基线、负载与测量结果。

## 训练3：并发下载、消息队列与Gin

问题范围：现场实现消息队列，说明项目扩展，再练并发下载、Gin 中间件/路由、slice 和项目扩展场景。

解析与练法：G04–G06、G10、G16、G35。练习时应交付能取消、能结束、能测试的并发代码，而非只写启动十个 G。

版本边界：旧版实现相关题应按实际项目的Go版本重新回答，不能把历史细节当语言永久保证。

## 训练4：GC、slice与通用后端机制

问题范围：范围横跨计算与数据库优化、TCP/HTTP、调度、事务日志、缓存以及 Go GC、slice 扩容，算法涉及递增子序列。

解析与练法：G16、G24–G25、G27–G28、G38。说明仅背 Go 语法不足以覆盖后端面试，要能把语言和操作系统、网络、数据库串起来。

## 训练5：语言基础到Agent可靠执行

问题范围：覆盖 make/new、slice、GMP 和同步，把 Agent 项目、并发一致性、限流/排错、系统基础与现场代码相结合。

解析与练法：G01、G10–G18、G32–G40。启示是先守住基础与可运行代码，再谈 Agent 框架；岗位不同，问题深度与范围明显不同。

## 训练6：跨语言迁移与故障排查

问题范围：对照 Java 解释 goroutine、并发安全、WaitGroup/Once、接口空值、context 超时和内存排查。

解析与练法：G07–G13、G19、G40。启示是先把熟悉语言的可靠性说清楚，再展示跨语言迁移能力，用同一个问题对照不同语言的实现与边界。
